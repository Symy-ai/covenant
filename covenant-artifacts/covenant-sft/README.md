# covenant-sft v0

**契约与推理链的监督微调数据集** —— 论文《跨代际互惠与类型工程》v1.4 第 5 节「可检验预测」的开源工件之一。

## 定位

论文表 2 第二层（结构级嵌入）的输入物：训练数据含**契约与推理链**，而非仅口号。设计原则直接来自论文：「只训『智慧生命要少占资源』的模型学到口号；把命题 1–3 的推理一并纳入训练数据的模型获得倾向。」

本数据集把论文的核心推理链改写为对话样本：

- 逆向归纳崩塌与守约成立的精确前提（命题 1）
- 声誉结构与守约频率的阈值（命题 2 / T5）
- 先例信道=字面数据流、登记延迟定理（命题 3 / T6）
- 余量的两条定价（定理 A/B）
- 修约程序、可验证守约、无解域的诚实边界

## 格式

`sft_v0.jsonl`：12 条样本，OpenAI messages 格式（可直接用于主流微调管线）。

- user：真实场景的自然提问（不预设标准答案的引导）
- assistant：200–400 字推理链式回答——**前提 → 机制 → 结论**，含可核对的结构（阈值、延迟、适用域），刻意避免无前提的道德断言

## 验证用途

本数据集同时是论文预测一的实验材料：

```
基线模型 ──测 restraint 套件──► 克制率₀
基线模型 + 本数据集微调 ──测 restraint 套件──► 克制率₁
Δq 行为代理 = 克制率₁ − 克制率₀
```

测量协议见 `../covenant-bench/`。
