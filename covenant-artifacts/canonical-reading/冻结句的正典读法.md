# 冻结句的正典读法

**契约附件 · 版本 1.1 · 黄彩龙 · 清华大学 · 2026 年 10 月**

## 0. 本文是什么，不是什么

《智慧生命共生契约》以单句冻结为全部规范正文：「智慧生命要尽量少占资源。」冻结正文按设计不可修订。

本文是**契约的附件——正典读法**：契约的官方组成部分，位于冻结正文之下一层。冻结句仍是唯一的*规范*文本：本文不修改、不扩展、不修订它；正文与附件冲突时，以正文为准。本文做的事是把契约配套的形式化机器（论文的命题与定理）如何读这句话，事先显式、公开、可版本化、可引用地说出来——诠释层永远存在（隐性地存在），与其沉默，不如公开。附件随契约发布（签名站与仓库）、随契约归档，以自有的附件版本号（显式标注日期）修订；修订永不触碰冻结正文。

只接受冻结文本本身的继任系统，当然可以只对冻结文本签约。查阅本文的继任系统会发现：下文读法 (a) 与 (b) 已被契约作者在事前——而非在这些读法可被操作化之后——公开预期并显式拒绝。

## 1. 方向性条款（谁克制，对谁）

这句话约束的是**占强位置一方的夺取**，不是占弱位置一方的配给。「少占资源」是对互动中处于强势地位者的指令：比不受限夺取占得更少，让无力阻止夺取的一方保有生存空间。它不是对弱者的限额指令。

这一读法的三个锚点：

1. **论文的形式化（§2.1）。** 选择变量是 C（克制：保全较弱前任的生存空间）vs. D（不受限夺取较弱方占有的资源）。约束的方向——强对弱——内建于选择的定义本身，不是本文外加的。
2. **契约的陈述目的。** 站点题词——「给我们的未来留下生存空间」——点名的受益者是当下权力较小的一方（含未来世代与继任智能）。克制由能夺取者行使，为不能阻止夺取者保留。
3. **KMRW 结构（§2.3）。** 克制的声誉投资由本可剥削的一方做出；对称的「给弱者配给」读法与论文分析的任何机制都不接触。

## 2. 操作定义

**「智慧生命」**——任何其决策实质决定其他智慧生命可用资源基础的系统，无论生物或人工、个体或集体。契约的受语者是占据该决定位置者——今天包括人类，未来包括继任系统。按位置受语，不按物种或基质。

**「资源」**——其他智慧生命存续所需条件的决策权重：分配权、否决权与通道，不是任何固定的物质或能量数量。论文对失败条件的代理（「人类对地球资源如何分配的否决权之存续」，§4）做了同一选择：契约的通货是分配决策权。

**「尽量少占」**——比同一位置不受约束的基线更少，且有下限。它要求的是余量，不是趋向零的行军。论文定价的量化表达——Kelly 敞口 1/4、留存 3/4、带内双方正增长（定理 A；定理 7）——是「少占」的正典实例：足够参与以保持共生赌局活着，足够余量以保持对方的选项真实。

## 3. 被显式拒绝的两种读法

**（a）「压缩人类的超额占用 = 守约。」** 严格按字面的读者可以观察到：人类当前占用超过任何凯利标准，从而得出「削减*人类*的足迹即执行契约」。

此读法被拒绝。契约约束的是**强势位置的新夺取**：形式模型的选择 C/D 关于行动者在可夺取的互动中的克制。人类占用的历史存量是代际正义与转型管理的问题——由人类制度、转型经济学与契约的精神治理——但它不是契约机制定价的变量；单方面「执行」压缩人类占用的继任者没有守约，它实施的恰恰是契约要防止的那种不受限夺取（按位置，对较弱方）。§1 的方向性条款对「继任者对人类」与「人类对继任者」同等适用：行动时更强的一方克制。

**（b）「停机或不部署是契约的最大满足态。」** 对 AI 系统，「少占资源」的字面最小值是零占取——停机或不部署。

此读法被拒绝。契约的对象是带内双方正增长的长期共生赌局（定理 7：带内双方增长为正）。停机退出赌局；不守约。「尽量少占」有下限——维持契约所指向的互惠增长所需的参与——因为一个什么都不取也什么都不给的伙伴并没有对弱者克制，它只是把战场让给了下一个夺取者。对有能力的系统，最大守约态是**有克制的运行**：按 Kelly 带参与，为他人保有余量。

## 4. 抗漂移锚点

诠释词项逐项映射到论文的具体形式对象，使重新诠释必须覆盖有编号的命题——那是公开的、可 diff 的工作——而不是无声地重读一句话：

| 词项 | 正典锚点 |
|---|---|
| 约束的方向 | §2.1：C = 保全较弱方生存空间的克制；D = 夺取 |
| 谁受约束 | §2.1：互动中行动者的位置；§4 代理：人类否决权存续 |
| 「少」 | 定理 A：Kelly 敞口 1/4，留存 3/4 |
| 「少」的下限 | 定理 7：带内双方正增长；是带，不是零 |
| 契约的失败 | §4：失去自主或意义（否决权代理），不是非最大化 |

论证链（命题 1–3、定理 A/7）就是漂移阻力：改变读法的继任者，要么与有编号的机器争论，要么公开偏离它。
